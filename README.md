# HP制作 ご希望シート

公開URL: https://homepage-request-sheet.netlify.app/
管理画面: https://homepage-request-sheet.netlify.app/admin.html

5ステップの選択肢と自由記述でHP制作の希望を受け付けるアプリです。コード管理はGitHub、公開はNetlify、回答保存と管理者認証はSupabaseを使います。

## 利用と管理
- 制作希望者には公開URLを送ります。活動名・連絡先・個人情報の同意が必須です。
- 希望の各項目は選択肢と自由記述を併用できます。未定の項目はとばせます。
- 数字ボタンで入力ステップへ戻れます。端末の下書きは30日間自動保存されます。
- 参考プレビューは最後の確認画面で開きます。文章の希望は文章のまま保存します。
- 保存済みの受付番号・日時を確認した場合だけ送信成功を表示します。
- 管理画面は登録済みのSupabase Authのメールアドレスとパスワードでログインします。
- 回答一覧・検索・個別詳細・対応状況・コピー・TXT/JSON保存が使えます。
- テスト回答はアーカイブに保存しています。アーカイブは削除ではありません。
- パスワード再設定先は本番のreset-password.htmlをSupabaseのRedirect URLsに登録済みです。別URLへ移す際は、先に新しい戻り先を登録してください。
- PWAは任意です。iPhoneではSafariの共有メニューからホーム画面に追加できます。送信にはオンライン接続が必要です。

## 公開と更新
Netlifyの専用プロジェクト名はhomepage-request-sheetです。Freeプランを利用しています。無料枠には利用上限があります。有料プランへの変更や追加購入は別途確認が必要です。

GitHubへの保存とNetlifyへの反映は別操作です。自動デプロイは現在接続していません。

```sh
node build.mjs
npx netlify-cli@27.12.0 deploy --dir dist --no-build --prod
```

既存の専用プロジェクトへリンクした状態で実行してください。別サイトの変更を避けるため、公開前にプロジェクト名を確認します。Netlifyの画面でdistフォルダを手動アップロードして更新することもできます。

## ファイル
- index.html / app.css: 利用者の入力画面と参考プレビュー
- admin.html / admin.js / admin.css: 管理者認証と回答管理
- reset-password.html / reset-password.js: パスワード再設定
- config.js: 公開可能なSupabaseキーのみ
- edge-function.ts: hp-request-submitのサーバー側ソース。Netlifyの静的公開フォルダには含めません。
- manifest.json / sw.js / アイコン: PWA
- _headers: キャッシュとブラウザ保護の設定
- build.mjs / netlify.toml: Netlify用の静的ビルド

## 個人情報とセキュリティ
- hp_requestsはRLSを有効にし、登録済み管理者だけが回答を閲覧できます。
- 一般利用者は回答一覧を読めません。送信は入力・同意・送信回数を検証するAPI経由です。
- 秘密キーはSupabaseの実行環境だけで扱い、公開ファイルに含めません。
- 回答・管理画面・認証APIはService Workerにキャッシュしません。
- 管理セッションはタブ単位です。共用端末ではログアウトしてください。
- 不要な回答は制作担当者が受付番号を確認して整理してください。削除依頼への対応はアーカイブとは別に行います。
- Supabaseの無料プロジェクトには利用枠と休止条件があります。停止や上限の通知を確認し、必要に応じて復帰してください。
